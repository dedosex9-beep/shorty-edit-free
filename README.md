# Shorty Edit Free

Premium beat-sync reel maker for product mockups and music.

## Quick Start

```bash
npm install
npm start
```

Then open http://localhost:3000

## Features

- 📸 Upload 10-50 product mockups (PNG/JPG)
- 🎵 Upload your music track (MP3/WAV/AAC)
- 🎬 Automatic beat detection and sync
- 🎨 3 premium visual styles (Cinematic, Luxury, Trendy)
- 📤 Export real 1080x1920 vertical MP4 video
- ⚡ Real-time progress tracking with beat visualization

## Workflow

1. Upload your mockup images in order
2. Upload your music track
3. Choose a visual style
4. Click "Generate Reel"
5. Watch the beat map appear as Shorty analyzes
6. Download your finished 30-second reel

## Tech Stack

- Node.js + Express
- FFmpeg for video composition
- Fluent-FFmpeg for audio/video processing
- Multer for file uploads
